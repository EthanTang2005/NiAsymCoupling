Cite the original source and data provider for the subset used. A curation-source paper, original measurement paper, and method paper can be different entities. ## TheLiaoGroup author dataset and ACS SI

The author dataset is referenced at [TheLiaoGroup/Enantioselective-Cross-Coupling-Prediction, pinned commit](https://github.com/TheLiaoGroup/Enantioselective-Cross-Coupling-Prediction/tree/22378a6aa054166f60977379c559e8451bf3fad7), associated with DOI [10.1021/acscatal.4c04277](https://doi.org/10.1021/acscatal.4c04277). The 2026-10-08 checks found no explicit license in the pinned repository tree, README, or searched workbook XML text. Embedded workbook objects were not visually reviewed.

The separate [official ACS Figshare SI object](https://api.figshare.com/v2/articles/27952871), DOI `10.1021/acscatal.4c04277.s001`, reports [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) and contains `cs4c04277_si_001.pdf`, not `Raw_Dataset.xlsx`. That SI license is not extended to the GitHub workbook by this project. This package preserves attribution and uncertainty; it does not assign the workbook a new upstream license.
